Apply the overlay

Harbor OS is not a relicensed Linux Mint ISO. Download the independent zip, then apply a flavor onto a declared Linux Mint 22.3 Cinnamon (or Debian-family) base.

  1. Download the overlay zip from the Harbor OS pane. No Grok App tab required.
  2. Unzip on the target machine. The tree is the overlay, not a bootable image.
  3. Make the control script executable: chmod +x scripts/harborctl.sh installer/*.sh
  4. Preview the garden without installing: ./scripts/harborctl.sh garden then open http://127.0.0.1:8080
  5. Apply the official flavor: HARBOR_FLAVOR_ID=zen-garden ./scripts/harborctl.sh apply
  6. Root on Mint/Debian copies the tree to /opt/harbor-os. Without root, files land under ~/.local/share/harbor-os.
