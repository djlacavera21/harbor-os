Full OS

Harbor does not host or relicense the Mint ISO. The bootable path is: verify the official image, boot it, apply the overlay.

Declared baselinuxmint-22.3-cinnamon-64bit.iso
sha256a081ab202cfda17f6924128dbd2de8b63518ac0531bcfe3f1a1b88097c459bd4
Upstream indexlinuxmint.com/download.php
Overlayharbor-os-main.zip
curl -L -o harbor-os.zip https://github.com/djlacavera21/harbor-os/archive/refs/heads/main.zip
unzip harbor-os.zip && cd harbor-os-main
bash iso/full-os-kit.sh /path/to/linuxmint-22.3-cinnamon-64bit.iso
# boot the verified Mint image, then:
bash iso/live-apply.sh

The kit refuses a mismatched filename or checksum. It does not fetch the ISO. A personal Cubic image is the operator’s artifact and must not be uploaded as a flavor pack.
