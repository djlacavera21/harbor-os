# Alignment

Harbor treats alignment as an install-time contract, not a slogan.

## Constraints encoded in software

- Visualizer binds to `127.0.0.1` only.
- Zen Master refuses live calls without an explicit key file.
- Flavor validator rejects missing base/identity fields so a flavor cannot hide its upstream.
- Community flavors default to `risk: unsigned`.
- First-boot script is a message plus a browser open, not a privilege escalation.

## What alignment is not

It is not a promise that Grok, xAI, or this repository shares every goal written in a flavor file. A flavor records *the operator's* stated principles. The agent is instructed to stay in an advisory role.

Propaganda, persuasion, and political messaging systems are operator content. This tree ships workspaces (Research, Design, Publishing, Strategy), not a built-in influence engine.
