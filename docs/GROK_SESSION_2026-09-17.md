# Grok session — 17 September 2026

## Ask

Work on a full OS with an independent download under an Experimentals tab
in the Grok App, plus a Premium+ submenu for community Harbor flavors.

## What shipped in 1.5.0

- Official overlay version bump to 1.5.0.
- Design Harbor community flavor (`flavors/design-harbor`).
- Local ingest server implementing the Premium+ upload contract
  (`experimentals/ingest.py`, `harborctl ingest`).
- Self-test (`harborctl selftest`).
- Design / Archives module tools.
- Catalog and Grok App manifest updated so a future tab still consumes
  the same JSON.

## What still only xAI can own

- Rendering Experimentals inside Grok iOS / Android / Web.
- Live X Premium+ entitlement checks.
- Official xAI / Grok branding on an operating system.
