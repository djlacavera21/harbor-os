# Experimentals

Harbor OS treats "Experimentals" as a **catalog**, not a hidden privilege.

## Official channel

`flavors/zen-garden` is the first listed official flavor. It can be downloaded by anyone with the git repo or the zip URL.

## Community channel (Premium+ proposal)

If the Grok App adds an Experimentals tab, X Premium+ is a reasonable upload gate:

- Uploader is an identifiable X account.
- Rate limits and review queue are possible.
- Running a downloaded flavor stays free — the gate is for *publishing* into the shared catalog.

Until that tab exists, community flavors land as pull requests against this repository.

## Risk labels

| Label | Meaning |
| --- | --- |
| low | Official tree, reviewed |
| medium | Reviewed community overlay |
| high | Broad system changes, still reviewed |
| unsigned | Not yet reviewed — run in a VM |
