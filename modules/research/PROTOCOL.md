# Research verification protocol

1. Capture — title, URL, retrieved date, format (html / pdf / note).
2. Classify — primary, secondary, official, anonymous, adversarial.
3. Extract — facts that can be checked independently.
4. Cross-check — at least one independent source for load-bearing claims.
5. File — verified notes go to `modules/archives/`; outbound drafts to `modules/publishing/`.

The Zen Master may draft a synthesis. It does not close a verification.
