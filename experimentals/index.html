Boundaries

Harbor OS is an independent overlay and flavor protocol maintained at github.com/djlacavera21/harbor-os.

  • It does not modify the Grok App binary.
  • It does not read live X subscription state.
  • It does not host a full Linux Mint ISO (use official Mint + Cubic).
  • It is not harboros.ai / TrueNAS SCALE HarborOS, and not the Rust Pi-4 harbor-kernel.
